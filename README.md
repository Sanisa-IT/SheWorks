# My JavaScript Website (starter)

This repository contains a minimal scaffold for a small JavaScript website.

Quick start

- Open [index.html](index.html) in a browser.
- Or run a quick local server (recommended):

```bash
npx http-server -p 8080
# then open http://localhost:8080
```

Files

- [index.html](index.html) — main HTML file
- [css/styles.css](css/styles.css) — basic styles
- [js/app.js](js/app.js) — simple JS starter

Next steps

- Add components in `js/` and styles in `css/`.
- Hook up a bundler (Vite/Rollup) if you need modules and hot reload.
